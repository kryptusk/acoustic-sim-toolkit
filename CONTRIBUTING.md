Thank you for considering contributing to the Acoustic Sim Toolkit! We welcome improvements, bug fixes, and new features.

To get started:

1. **Fork this repository** to your GitHub account.
2. **Create a feature branch** for your changes:

    git checkout -b feature/your-feature-name

3. **Make your changes**. Please follow these guidelines:
    - Write clear, concise code and follow [PEP8](https://peps.python.org/pep-0008/) style guidelines.
    - Add or update docstrings and comments to explain the purpose of functions and modules.
    - When appropriate, update the documentation or example scripts to reflect changes.
    - Avoid breaking existing functionality; if you change public APIs, explain why in the pull request.
    - Test your changes by running existing simulations (e.g., `python main.py`) with different configurations.

4. **Commit your changes** with a descriptive commit message:

    git commit -m "Add feature X to improve Y"

5. **Push the branch** to your fork:

    git push origin feature/your-feature-name

6. **Open a Pull Request** on GitHub:
    - Navigate to your fork on GitHub and click the “Compare & pull request” button.
    - Describe what your changes do and why they are needed.
    - Link any relevant issues or discussions.
    - Be ready to answer questions or make adjustments based on feedback.

Thanks for your contribution!
